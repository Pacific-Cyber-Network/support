## 📌 How to Join the Organization?

Want to display the organization badge on your GitHub profile and collaborate on repos?

1. Go to the **[Issues](https://github.com/Pacific-Cyber-Network/support/issues)** tab.
2. Click **New Issue** with the title: `Request to join Pacific-Cyber-Network`.
3. Drop your GitHub username in the description (e.g., `@your-username`).
4. You'll receive an invitation shortly!
