## 📌 How to Join the Organization?

We welcome developers, students, and open-source contributors from all over the world!

1. Go to our **[Issues Tab](https://github.com/Pacific-Cyber-Network/support/issues)**.
2. Click **New Issue** and use the title: `Request to join Pacific-Cyber-Network`.
3. Put your GitHub username in the description (e.g. `@ziwei-sys`).
4. You will receive an organization invite directly on GitHub!
